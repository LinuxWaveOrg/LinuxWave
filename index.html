About LinuxWave

关于LinuxWave

LinuxWave is the official Linux port of MacWave. Starting with MacWave 2.0, the main MacWave project no longer supports Linux, so LinuxWave carries that support forward. It is a package manager that runs on Linux (x86_64 / arm64), designed to host common software packages for Linux software developers.

LinuxWave 是 MacWave 的官方 Linux 移植版。从 MacWave 2.0 起，MacWave 主线不再支持 Linux，LinuxWave 承接了这部分支持。它运行在 Linux（x86_64 / arm64） 上，是一个为 Linux 软件开发者 托管 常用软件包 的 包管理器。

Why LinuxWave

为什么选择 LinuxWave

  • One command, install common packages. No more scattered download links.
  • Versioned storage. Every binary is stored as package@version, so multiple versions can coexist without conflicting with system tools.
  • Optional unversioned links. wave link <package> adds a plain shortcut pointing at the highest installed version, and re-points itself whenever you install or remove versions.
  • Fully isolated. Upgrade-proof. LinuxWave operates entirely within its own dedicated directories and never overwrites or links against distribution libraries - the dependency libraries it does ship are relocated into its own tree. Even across major distribution upgrades, your LinuxWave environment remains completely intact and functional.
  • No cache, always up to date. Package metadata is fetched live from the infosource branch.
  • 10 archive formats, CI-verified. Supports no-extension binaries, .zip, .tar.gz, .tar.bz2, .tar.xz, .tar, .gz,.xz, .bz2, .conda.
  • Verify first, extract later. SHA256 is checked before extraction.
  • Resumable downloads. Interrupted? Resume with -C.
  • Lightweight and transparent. Pure Python + Shell. No heavy runtime, no hidden behavior.
  • Automatically manage dependencies. Support for software packages with dependencies, using reference counting and automatic dependency management, with no need to handle dependencies manually.
  • 一条命令，安装常用软件包。 不再需要到处寻找下载链接。
  • 版本化存储。 每个二进制文件都以 package@version 形式存储，因此多个版本可以共存，且不会与系统工具冲突。
  • 可选的无版本号链接。 wave link <包名> 会建立一个指向最高已安装版本的普通快捷方式，并在安装或卸载版本时自动改指。
  • 完全隔离，无惧升级。 LinuxWave 完全在自己的专用目录中运行，绝不覆盖或链接发行版自带的库——它附带的依赖库会被重定位到自己的目录树内。即使跨越大版本发行版升级，你的 LinuxWave 环境依然完整可用。
  • 无缓存，始终最新。 软件包元数据实时从 infosource 分支获取。
  • 支持 10 种归档格式，经 CI 验证。 支持无扩展名二进制文件、.zip、.tar.gz、.tar.bz2、.tar.xz、.tar、.gz、.xz、.bz2、.conda。
  • 先校验，后解压。 解压前先校验 SHA256。
  • 支持断点续传。 下载中断了？用 -C 继续。
  • 轻量透明。 纯 Python + Shell，无重型运行时，无隐藏行为。
  • 自动管理依赖。 支持带依赖的软件包，采用引用计数与自动依赖管理，无需手动处理依赖。

Install LinuxWave

安装 LinuxWave

In the terminal, run:

在终端中运行： 

$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Sha0huaZhang/LinuxWave/HEAD/lib/install.sh)" && source ~/.zshrc

(If you are using bash instead of zsh, run source ~/.bashrc)

（如果你使用的是 bash 而非 zsh，请运行 source ~/.bashrc）

Requirements: Linux (x86_64 / arm64), Python (3.14 and above), patchelf (for dependency library relocation).

环境要求：Linux（x86_64 / arm64）、Python（3.14 及以上）、patchelf（用于依赖库重定位）。

Uninstall LinuxWave

卸载 LinuxWave

To completely remove LinuxWave from your system, run the following command in your terminal:

要从系统中彻底移除 LinuxWave，请在终端中运行以下命令： 

$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Sha0huaZhang/LinuxWave/HEAD/lib/uninstall.sh)"

Download Directory

下载目录

Installed binaries are stored in (options):

已安装的二进制文件存储于（可选）： 

1. ~/.local/linuxwave
2. /opt/linuxwave
3. /usr/local/linuxwave
4. /home/linuxwave/.linuxwave (shared, all users)
5. Custom

Config file is stored in (a system-level install always takes priority):

配置文件存储于（系统级安装始终优先）： 

1. /etc/linuxwave_config          system-level install (needs sudo)
2. ~/.config/linuxwave_config     user-level install (no sudo)

A shared install (option 4) always uses /etc/linuxwave_config, so that every user on the machine resolves the same install. It needs patchelf, Python 3.14+ and sudo once; the linuxwave account is created automatically if it does not exist.

共享安装（选项 4）始终使用 /etc/linuxwave_config，以保证全机所有用户解析到同一个安装。需要 patchelf、Python 3.14+，以及一次性提供 sudo；若 linuxwave 账号不存在会自动创建。

Run Packages

运行软件包

To run a package, run the following commands in your terminal:

要运行某个软件包，请在终端中运行以下命令： 

{package_name}@{version}

Use the versioned name {package_name}@{version}, or run wave link {package_name} once and then just type {package_name}.

使用带版本号的名称 {package_name}@{version}，或先运行一次 wave link {package_name}，之后直接输入 {package_name} 即可。

Command Reference

命令参考

Usage:
  wave <command> [package] [flags]

Commands:
  install     Install a package (Latest Version)
  uninstall   Uninstall a package
  list        List installed packages
  search      Search for a package in the index
  info        Display detailed information about a package
  selfupdate  Update LinuxWave itself
  link        Link installed packages without a version number
  unlink      Remove those unversioned links
  linkquery   Show which version an unversioned link points to
            
Flags:
  -h, --help              Show help for any command
  -V, --version           Print version information
  -v, --verbose           Enable verbose output (show detailed logs)

Global Flags (can be used with any command):
  -C, --continue          Resume interrupted downloads (like curl -C -)
      --proxy string      Specify an HTTP/HTTPS proxy (e.g., http://127.0.0.1:8080)
      --skip-ssl          Skip SSL certificate verification (insecure)
      --limit-rate string Limit download speed (e.g., 200K, 1M, 5M)
      --ver string        Install a specific version of the package

Special Flags:
wave install <pkgname>@<version>   Download certain version(s) of a package
    --unlink                       Leave the unversioned link alone (install / uninstall)
    --all, -a                      Apply to every installed package (link / unlink / linkquery)

Unversioned Links:
wave link <name>                   Link a package to its highest installed version
wave linkquery <name>              Show what <name> is linked to (e.g. 🌊 ffmpeg@9.0)
wave unlink <name>                 Remove that link

Uninstalling a version re-points the link to the next highest one, and removes
the link when no version is left. uninstall --unlink keeps the link as-is, and
refuses to run when that would leave the link pointing at the version you are
removing.
