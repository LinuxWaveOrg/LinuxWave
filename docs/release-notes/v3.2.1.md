# 安全更新

**LinuxWave 3.2.1** · Build number: **312A1137** · 发布于 **2026-11-08** · 发布分支：`3.2`

> 建议所有用户升级。这一版堵掉两个「安装/卸载时按路径递归改权限、删目录」的漏洞，
> 与 MacWave 4.3.0 / 4.3.1 修的是同一类问题。命令、数据格式、安装布局都不变。

## 为什么要升级

### ① 装到系统目录时，会把那个目录整个接管过来

`install.sh` 的目录校验以前只挡了 `..`、控制字符、非 ASCII、相对路径、`//` 和 `/`。
之后的动作是：

```bash
sudo chown -R root:root "$BASE_DIR"          # 非共享的系统级安装（3.2.1 起）
sudo chown -R "$CURRENT_USER": "$BASE_DIR"   # 3.2.1 之前的写法
rm -rf "$BASE_DIR"                           # 拒绝协议时的回滚
```

如果 `BASE_DIR` 是 `/usr/local` 这种「别的软件的家」，这两件事分别是**把整个目录接管过来**
和**删掉它**。实测旧版的校验对下面这些路径全部放行：

```
/usr/local   /opt   /etc   /usr   /bin   $HOME
```

**3.2.1 起**：这些系统目录本身一律拒绝（按完全相等判，`/opt/linuxwave` 这类子目录不受影响）；
已存在且非空、又不是 LinuxWave 安装的目录也拒绝。

### ② 安装/卸载会顺着配置里的路径删目录

`uninstall.sh` 从 `config.json` 读 `base_dir`，只要不在 `$HOME` 下就直接 `sudo rm -rf`。
用户级配置对任何以该用户身份运行的进程都可写 —— 一条被改过的 `base_dir` 就能删掉
`/usr/local` 或家目录。

**3.2.1 起**：只删确实含 `lib/wave.py` 的 LinuxWave 安装树；系统目录、`$HOME`、
非 LinuxWave 目录一律跳过，并逐条说明理由：

```
🌊 Skipping /usr/local: a system directory.
🌊 Skipping /home/you: your home directory.
🌊 Skipping /opt/other-tool: not a LinuxWave install (no lib/wave.py).
🌊 Nothing was deleted there. If you are sure, remove it yourself.
```

## 顺带收紧：系统级安装树归 root

`/opt/linuxwave`、`/usr/local/linuxwave` 这类**非共享**的系统级安装，树以前归安装者所有，
`links/<名>` 对该用户可写，而它在系统 `PATH` 上会被别的用户、脚本甚至 root 执行 —— 本地提权。
现在这些安装树变成 `root:root`、权限 755：所有人可读可执行，改动需要 `sudo`。

代价说清楚：装包/升级/卸载要写全路径，因为 `sudo` 用的是它自己的 `PATH`：

```
sudo /opt/linuxwave/lib/wave install <包名>
```

想要「不带 `sudo` 的 `wave install`」，用共享安装（选项 4）—— 那条路不受本版影响，
仍然由 `linuxwave` 组共享写。运行时会在**下载之前**检查可写性，并给出可照抄的命令。

## 回归

新增 `scripts/dir_guard_test.sh`，62 条断言，纯离线、秒级：

| 覆盖 | 内容 |
| --- | --- |
| 判定 | 25 个系统目录、`$HOME`、非 LinuxWave 目录 → 拒绝；`/opt/linuxwave`、`/usr/local/linuxwave`、`~/.local/linuxwave` → 放行 |
| 防误杀 | 已有 `lib/wave.py` 的安装树仍可重装/升级 |
| 旧校验 | 空、`..`、相对路径、`/`、`//` 仍然拒绝 |
| 属主 | 非共享系统级安装归 `root:root`、755 语义；交还在写 launcher 之后；共享安装仍归 `linuxwave` |
| 卸载 | 用一个假的 `sudo` 真跑卸载脚本：非 LinuxWave 目录、`$HOME` 保留，真正的安装树照常删除 |

## 兼容性

- **不涉及命令行变更**：没有新增、删除或改变任何旗标。
- **不涉及数据格式变更**：索引、配置都不变。
- **安装布局不变**：还是 `lib/`、`pkg/`、`surfboard/`。
- **行为变化两处**：系统目录不再能当安装根；非共享的系统级安装改成 `root:root` 755，
  之后改动软件包需要 `sudo`（共享安装不受影响）。

## 升级方式

```bash
wave selfupdate
```

（`selfupdate` 会重写 root 属主的 `/etc/linuxwave_config`，因此会提示一次 `sudo`。）

已有的共享安装照旧；已有的非共享系统级安装升级后仍是原属主，**重新跑一次 `install.sh`**
才会转成 `root:root`。
