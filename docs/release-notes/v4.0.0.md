## 这一版做了什么

### 安装目录菜单重排：共享安装升为第 1 项（推荐）

`/home/linuxwave/.linuxwave`（Linuxbrew 式共享安装，等价 `/home/linuxbrew`）现在是菜单第
`1` 项，并标记为推荐项；其余选项依次顺延：

```
1. /home/linuxwave/.linuxwave (shared, all users) [recommended]
2. ~/.local/linuxwave
3. /opt/linuxwave
4. /usr/local/linuxwave
5. other (enter custom directory)
```

> 顺带把定位写清楚：和 Linuxbrew 一样，LinuxWave 是**补充而不是取代**——`apt` /
> `dnf` / `pacman` 仍负责系统组件、库与驱动，LinuxWave 只补发行版没有或版本太旧的开发
> 软件，不接管、也不删除任何由发行版管理的包。共享安装之所以成为推荐项，是因为它最贴合
> 这个定位：一台机器装一次，所有人可用，又完全在自己的树里。

两个连带变化，升级或写脚本时必须注意：

- **`--ci`（原 `-S` / `--silent`，本版更名）不带 `--dir-option` 时的默认项随之变成第 1 项**，也就是共享安装：它需要免密
  `sudo`（或 root）来建 `linuxwave` 账号、写 `/etc/linuxwave_config`。想要免提权的用户级安装，
  显式写 `--dir-option=2`。
- **`--dir-option=N` 的编号整体变了**：写死旧序号的地方要跟着改（旧 1 → 新 2，旧 4 → 新 1）。

### What this release does

### Directory menu reordered: the shared install is now entry 1 (recommended)

`/home/linuxwave/.linuxwave` - the Linuxbrew-style shared install, equivalent to
`/home/linuxbrew` - is now menu entry `1` and is marked as the recommended choice; every
other entry moves down by one (see the list above).

> This is also where the positioning becomes explicit: like Linuxbrew, LinuxWave is a
> **supplement, not a replacement**. `apt` / `dnf` / `pacman` still own system components,
> libraries and drivers; LinuxWave only adds developer software your distro does not ship,
> or ships too old, and never takes over or removes a distro-managed package. The shared
> install is the recommended entry precisely because it fits that role: install once per
> machine, usable by everyone, entirely inside its own tree.

Two follow-on effects worth knowing before you upgrade or write a script:

- **The `--ci` default (used when `--dir-option` is omitted; the flag used to be
  `-S` / `--silent`) is now entry 1**, i.e. the
  shared install, which needs passwordless `sudo` (or root) to create the `linuxwave` account
  and write `/etc/linuxwave_config`. For a privilege-free per-user install, pass
  `--dir-option=2` explicitly.
- **The `--dir-option=N` numbering changed**, so hard-coded numbers must be updated
  (old 1 → new 2, old 4 → new 1).

## 新增安装器旗标 `--skip-platform-check`

拿安装器调试、或者在手上没有目标机器的时候演练一遍时用：它跳过「只装 Linux」那道
闸门，并且**明确警告**当前是什么系统、装出来的东西在本机没验证过。常规用法是配
`--dry-run`（只看要做什么，不落盘）：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/LinuxWaveOrg/LinuxWave/4.0-dev/lib/install.sh)" \
  -- --skip-platform-check --ci --dry-run --dir-option=2
```

顺带把开头两道闸门（平台、bash 版本）的输出并进统一输出层：它们现在跟其余提示一样
认 `--zh` 与 `--raw`，不再是「中英各打一行、`--raw` 下还带 🌊 与颜色」。

### Installer flag `--skip-platform-check`

For debugging the installer, or rehearsing an install on a machine that is not the target
one: it skips the "Linux only" gate and **says so loudly**, including which system this is
and that the result is untested here. Normally used together with `--dry-run`:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/LinuxWaveOrg/LinuxWave/4.0-dev/lib/install.sh)" \
  -- --skip-platform-check --ci --dry-run --dir-option=2
```

The two opening gates (platform, bash version) now go through the same output layer as
everything else: they honour `--zh` and `--raw` instead of printing one line per language
and keeping the 🌊 and colours under `--raw`.
