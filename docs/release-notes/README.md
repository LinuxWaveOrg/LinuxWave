## 约定

- **正文写法**：中英双段（`## 这一版做了什么` / `### What this release does`）+ 实测数据 +
  已知限制 + 附件清单 + 归档 sha256 + `# Install 安装` 页脚。参照 [v3.1.0](v3.1.0.md)。
- **发布日**：历史上构建日与发布日都落在同一天，所以 `release_date` 一直等于
  `publishedAt`。**3.1.0 是第一个例外**（10-23 构建、10-29 发布），两者到底以哪个为准
  尚未决定——在决定之前，改动 `release_date` 要连着 `README`×2、官网、`configdata`
  一起改，别只改一处。
- 归档附带 `PROJECT_CONTEXT.md`，它是随 Release 发出去的文档，**落后于代码就等于发错文档**。
  归档是**发布当时的快照**：仓库后续更新文档不会让它失效，已发布的 sha256 依然有效。
